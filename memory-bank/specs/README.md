# Specs

This directory contains all the specs for this project.  Files will be named `<spec index number>-<spec name>.md` and will contain both the Spec and the frontmatter metadata for said Spec.

## Spec content

Specs will contain:
- End-user requirements with a who, a what, and a why.
- Functional requirements.
- Safety requirements if there are any.
- Regulatory requirements if relevant.
- Customer preference if relevant.
